# Дашборд с виджетами

Автор: Королева Анастасия Дмитриевна

## Архитектура

index.html — точка входа
main.js — инициализация, кнопки, часы, пасхалка, параллакс
js/
├── UIComponent.js — базовый абстрактный класс
├── ToDoWidget.js — виджет «Список дел»
├── QuoteWidget.js — виджет «Цитата дня»
├── WeatherWidget.js— виджет «Погода» (API)
├── CryptoWidget.js — виджет «Курс крипты» (API)
├── Dashboard.js — управляет виджетами
├── ThemeManager.js — переключение темы
├── Confetti.js — конфетти внутри карточки
└── ConfettiGlobal.js — салют эмодзи
styles/
├── main.css — общие стили и переменные тем
└── components.css — стили виджетов

## Источники данных (2 API)

1. Погода — Open-Meteo: https://open-meteo.com/
2. Курс крипты — CoinGecko: https://www.coingecko.com/en/api

## Запуск

ES6-модули требуют HTTP. Открой проект через Live Server в VS Code 

## Ограничения

- Список городов (СПб) и монет (BTC, ETH, SOL) фиксирован.
- Данные не сохраняются между перезагрузками (кроме темы).

## Журнал применения ИИ

Код сгенерирован ИИ и проверен вручную: каркас классов, стили, API-интеграция, мини-график BTC, пасхалка и часы.
